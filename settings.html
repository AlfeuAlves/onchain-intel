Detalhes das Fontes de Dados

CoinGecko API Agregador global usado para obter preços médios de mercado e variações percentuais. É a fonte primária de cotações para Bitcoin, Ethereum e Solana.
Alternative.me (F&G) Fornece o Crypto Fear & Greed Index, analisando volatilidade, volume e redes sociais para quantificar o sentimento emocional do mercado.
Blockchain.info Interface direta com a rede Bitcoin para capturar transações em tempo real que circulam no Mempool e blocos recentes.
BlockCypher API Monitora a rede Ethereum para detectar movimentações de baleias e validar o status da rede e taxas (Gas).
Sobre este Sistema

Este sistema é estritamente informativo. Ele observa blockchains públicas, transforma dados técnicos em estruturas padronizadas e disponibiliza inteligência sem executar ações financeiras.
